## Writing/Prob1/chapter2.typ — 手机版排版适配

用户把版面改成手机尺寸后发现长公式被 Typst 等比压缩，视觉很差。本轮完成：

### 1. 长公式一律手工换行
- 不能依赖那个「过宽自动缩放」的 show rule（它会把公式缩成小字），要在源码里拆：
  `$ A = B = C $` → `$ A = B $` + `$ = C. $`
- 拆分后若末尾只剩 `quad (k = 0,1,...)` 之类的条件，**不要单独居中成一行**，改成正文 `#h(2em)其中 $k = ...$。`
- 一个题干带多个小问时，拆成独立例题（例 x.x.x.1 / .2 / .3），比在一行里塞三个积分好

### 2. 公式表改为单栏
- 原两栏 grid 在手机宽度下每栏只剩一半，含积分号/分式的条目被压成小字
- 改为 `grid(columns: 1, row-gutter: 0.8em, align: center, ..rows.map(r => f(r)))`，`f(x) = math.equation(block: true, x)`
- `stack(spacing:)` 控制不住行距，用单列 grid 的 `row-gutter` 才有效
- 单栏后正文里「下表右栏给出…」这类措辞要一并改掉

### 3. 表格统一用三线表
新增 `datatable(header, body)` 函数（文件开头，紧跟在公式 show rule 之后）：
```typst
#let mt(x) = math.equation(block: true, x)
#let datatable(header, body) = align(center, block(above: 0.9em, below: 0.9em, breakable: false,
  table(columns: header.len(), align: center + horizon, inset: (x: 0.7em, y: 0.42em),
    stroke: none, table.hline(stroke: 0.8pt), table.header(..header.map(h => mt(h))),
    table.hline(stroke: 0.5pt), ..body.map(row => row.map(c => mt(c))).flatten(),
    table.hline(stroke: 0.8pt))))
```
已用于：例 2.2.2.1 分布列、例 2.5.1.1 二项分布列、例 2.5.2.1 泊松分布列、例 2.5.3.1 超几何 vs 二项对照、2.4.3 常见分布期望方差汇总表（4 列）。`breakable: false` 是必要的，否则整表会被拆到两页且第二页丢表头。

## Typst 语法坑（本轮新增）

- `bar(A_1)` 渲染成竖线不是上划线，必须用 `overline(A_1)`
- `p_X(x)` 会把 `(x)` 一起吞进下标，显示成 `p_{X(x)}`；要写成 `p_X (x)`（中间加空格）
- 同理 `C_V(X)` → `C_V (X)`，`F_Y(y)` → `F_Y (y)`
- 段首 `#h(2em)(2) ...` 报 `expected function`，须写 `#h(2em)#[(2) ...]`
